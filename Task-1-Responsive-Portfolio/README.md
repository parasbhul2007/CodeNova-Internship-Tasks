# Task 1 - Responsive Portfolio Website

## Features

- Semantic Hero, About, Skills, Projects and Contact sections.
- Responsive mobile, tablet and desktop layouts using CSS Grid, Flexbox and media queries.
- Accessible mobile navigation with `aria-expanded`.
- Light/dark theme toggle with localStorage persistence.
- Contact form validation and mailto handoff.
- Skip link and reduced-motion support.

## Tech stack

HTML5, CSS3, Vanilla JavaScript.

## Run locally

Open `index.html` in a browser or use VS Code Live Server. Replace `YOUR_EMAIL@example.com` in `script.js` with your email address before publishing.

## Required responsive screenshots

Capture the site at 375px (mobile), 768px (tablet) and 1280px+ (desktop). Save as `screenshots/mobile-375.png`, `tablet-768.png`, `desktop-1280.png`. Check that there is no horizontal overflow.

## Deploy

GitHub repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Add your real live URL here after deployment.
